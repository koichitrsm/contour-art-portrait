# CONTOUR ART — Portrait Edition (English UI)

A portrait-oriented interactive art app for smartphones.

## Features
- Tap three times to place three terrain peaks.
- After the third tap, the terrain gains color and transforms into a 3D bird's-eye view.
- The lowest areas are colored ocean blue.
- Green slopes contain approximately 420 thin black tree-trunk lines.
- 15 contour levels.
- Use RESET to start again.

## Files
- `index.html` — app
- `manifest.webmanifest` — add-to-home-screen settings
- `sw.js` — offline cache
- `README.md` — this guide

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload all four files to the root of your GitHub repository.
3. Open Settings → Pages.
4. Select `Deploy from a branch`, branch `main`, folder `/ (root)`, then Save.
5. Open the published URL on your smartphone.

## Add to iPhone Home Screen
Open the published URL in Safari, tap Share, then choose “Add to Home Screen”.

## Note
The 3D view is a simulated perspective projection rendered with Canvas. Please test the published app on your smartphone.
